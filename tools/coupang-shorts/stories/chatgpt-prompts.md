# ChatGPT 이미지 프롬프트

ChatGPT(이미지 생성)에서 **새 대화**를 열고 아래 순서대로 보내세요.
만든 이미지는 다운로드해서 `stories/soondubu/`, `stories/dakhanmari/` 폴더에 표의 파일 이름으로 저장합니다.

- 장면 이미지는 **가로 4:3**, 표지(00번)는 **정사각형**으로 요청합니다.
- **08번(제품 사진)은 ChatGPT로 만들지 마세요.** 실제 쿠팡 상품 이미지를 캡처해서 넣어야 합니다. 브랜드 포장을 AI로 그리면 상표 문제와 허위 표시 문제가 생길 수 있습니다.

## 1단계: 캐릭터와 화풍 정하기 (처음 한 번만)

```
지금부터 쇼츠용 일러스트를 여러 장 만들 거야. 모든 그림에서 아래 캐릭터와 화풍을 똑같이 유지해줘.

[캐릭터] 20대 한국인 여자 자취생. 갈색 웨이브 단발머리, 큰 갈색 눈, 볼이 살짝 발그레함. 베이지색 후드티를 입음.
[화풍] 부드러운 파스텔톤 한국 웹툰 스타일, 따뜻한 조명, 깔끔한 선, 귀여운 표정. 글자나 말풍선은 그리지 마.
[비율] 따로 말하지 않으면 가로 4:3.

먼저 이 캐릭터가 원룸 책상에 앉아 손 흔드는 기본 그림 1장을 그려줘.
```

캐릭터가 마음에 들면 다음 단계로 넘어가세요. 마음에 안 들면 "머리를 더 길게" 처럼 고쳐 달라고 하면 됩니다.
